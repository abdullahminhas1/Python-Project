## Python-Project 
Exploratory data analysis (EDA) on property listings scraped from Zameen.com to uncover 
what drives property prices across Pakistani cities.

## What's Inside
- Data cleaning: duplicates, messy columns, unit conversions (marla/kanal → sqft)
- Missing value treatment with justified imputation
- Fuzzy matching to standardize city/location names
- Outlier detection using IQR and Z-score methods
- Feature engineering for deeper analysis
- Univariate & bivariate analysis with interactive visualizations
- Investor-focused insights and recommendations

## Dataset
Zameen.com property listings — includes city, location, price, area, 
property type, beds/baths, and listing date.

## Tools
Python · Pandas · NumPy · Matplotlib · Seaborn · Plotly · FuzzyWuzzy
